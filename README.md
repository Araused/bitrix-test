# Модуль курсов валют (Тестовое задание)

Тестовое задание PHP-разработчика (Bitrix).

## Структура репозитория
- `/my.currency` — исходный код модуля.
- `/examples` — инструменты для быстрой проверки:
    - `seed.php` — скрипт для автоматического наполнения БД тестовыми данными (курсы 4 валют за последние 10 дней).
    - `page.php` — пример публичной страницы с подключенным фильтром и списком.

## Установка
1. Скопируйте папку `my.currency` в директорию `/local/modules/` (или `/bitrix/modules/`).
2. Перейдите в административную панель: **Marketplace -> Установленные решения**.
3. Найдите модуль **«Курсы валют (Тестовое задание)»** и нажмите **Установить**.
   *При установке автоматически создастся таблица в БД и скопируются компоненты в `/bitrix/components/my/`.*

## Как проверить работоспособность
1. Разместите файл `examples/seed.php` в корне сайта и запустите его в браузере для наполнения таблицы данными.
2. Разместите файл `examples/page.php` в корне сайта.
3. На странице `<site_address>/page.php` будет форма фильтрации и таблица с пагинацией.

## Деинсталляция
При удалении модуля через админ-панель:
- Таблица `my_currency` удаляется из БД.
- Папки компонентов удаляются из `/bitrix/components/my/`.
